### 🔍 Interactive Features
When you open the live diagram, you can:
* **Hover & Highlight:** Hover over any table to instantly trace its foreign key relationships.
* **Move & Zoom:** Drag tables around dynamically to focus on a particular schema subsystem.

> 🔒 **Note:** This live link is **view-only**. Any visual adjustments or panning you do on the canvas will not alter the master architectural design.
